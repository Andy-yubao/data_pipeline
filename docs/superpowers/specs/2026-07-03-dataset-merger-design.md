## 概述

开发 `data_merger.py`，将多个 `datas/` 图片目录合并到一个目标目录。每个数据源可独立指定采样比例（按比例随机抽取），目标目录不存在时自动创建。

## 架构

```
data_pipeline/
├── data_reviewer.py      # 审核清洗 (已有)
├── data_processor.py     # 标准化增强 (已有)
├── data_launcher.py      # GUI 面板 (已有，需修改)
├── data_merger.py        # 【新增】数据集合并
└── README.md             # (需更新)
```

**模块关系：**

```
data_launcher.py ── GUI ──┐
                          ├──▶ data_reviewer.run_reviewer()
                          ├──▶ data_processor.create_tub()
                          └──▶ data_merger.merge_datasets()  ← 新增
```

`data_merger.py` 提供核心函数 `merge_datasets(src_map, output_dir)` 作为唯一入口。CLI 和 GUI 均调用此函数，与 `data_processor.create_tub()` 模式一致。

## 核心流程

```python
merge_datasets(src_map: dict[str, float], output_dir: str) -> None:
```

- `src_map` = `{ "路径": 比例, ... }`, 比例范围 `0.0 ~ 1.0`
- `output_dir` = 目标目录路径

**步骤：**

1. **校验** — 每个 src 目录存在（否则报错退出），ratio 在 0.0~1.0（否则报错退出），output_dir 不存在则 `os.makedirs` 创建
2. **扫描** — `glob` 收集每源所有 `.jpg` 文件
3. **抽样** — 每源按 ratio 随机采样（`random.sample`）。ratio=1.0 时全取不随机。源目录无 .jpg 时打印警告并跳过
4. **复制** — `shutil.copy2` 逐文件复制到 output_dir。同名文件跳过（先到先得），打印 `WARNING: 跳过重复文件: xxx.jpg (来自 {源目录})`
5. **报告** — 打印统计摘要：每源取了/总数、跳过数、合并总数、输出目录

**错误处理：**

| 情况 | 行为 |
|------|------|
| src 目录不存在 | 报错退出，列出无效路径 |
| ratio 超出 0.0~1.0 | 报错退出，列出无效比例 |
| src 目录无 .jpg | 打印 WARNING，跳过该源继续 |
| 目标目录已存在且非空 | 打印 WARNING 但继续（不覆盖已有文件） |
| 同名文件冲突 | 跳过，打印 WARNING，先到先得 |

## CLI 设计

```bash
python data_merger.py \
  --src user/clockwise_none/datas:0.6 \
  --src user/clockwise_barrier/datas:1.0 \
  -o user/combined/datas
```

| 参数 | 说明 |
|------|------|
| `--src PATH:RATIO` | 可重复多次，指定源目录和采样比例 |
| `-o, --output PATH` | 目标目录（必填，不存在则自动创建） |

无默认值，所有参数必填。

## GUI 设计

在 `data_launcher.py` 现有界面中新增「数据集合并」区域，位于目录设置区与增强参数区之间：

```
┌─────────────────────────────────────────────┐
│  数据集合并                                  │
│  ┌──────────────────────────────────────┐   │
│  │ 源01: [______________] [浏览] 比例 [60]% │
│  │ 源02: [______________] [浏览] 比例 [100]%│
│  │ [+ 添加数据源]                          │
│  └──────────────────────────────────────┘   │
│  目标目录: [______________] [浏览]          │
│  [合并数据集]                               │
└─────────────────────────────────────────────┘
```

- 默认显示两行数据源输入框
- 每行：路径输入框 + 浏览按钮 + 比例 Spinbox（0-100，对应 0%~100%）
- 「+ 添加数据源」按钮动态追加新行，无上限
- 「合并数据集」按钮在后台线程执行，结果输出到日志面板
- 执行前校验：至少一个源有路径输入

## 测试要点

1. 单源 100% 复制 → 目标目录文件 = 源目录文件
2. 单源 50% 采样 → 目标约末源半数
3. 多源不同比例 → 总数正确
4. 同名文件冲突 → 跳过 + 警告
5. 空源目录 → 警告跳过
6. 目标目录不存在 → 自动创建
7. ratio=0.0 → 跳过该源
8. 无效 ratio → 报错退出
